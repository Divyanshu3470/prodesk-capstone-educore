# EduCore – AI-Assisted Development & Research Log

## Overview

This document records the AI-assisted research and technical exploration conducted during the planning phase of the EduCore Capstone Project.

AI tools were used selectively to explore implementation approaches, evaluate architectural decisions, clarify technical concepts, and improve project documentation. Final technology choices, feature prioritization, and design decisions were reviewed and adapted according to the project requirements.

## 1. Product Planning & Requirements

**Objective:** Define the scope and functional requirements of the LMS.

**Research Areas:**
- LMS architecture and user roles.
- Student and instructor workflows.
- MVP feature prioritization.
- Scope management for a five-week development cycle.

**Key Outcome:** Defined the initial scope of EduCore, separating essential MVP functionality from future enhancements.

## 2. Technology Stack Evaluation

**Objective:** Evaluate technologies suitable for a full-stack application.

**Technologies Evaluated:**
- React.js and Vite for frontend development.
- Tailwind CSS for UI styling.
- Node.js and Express.js for backend services.
- MongoDB and Mongoose for data persistence.
- JWT and bcryptjs for authentication.

**Key Outcome:** Finalized the Fullstack Developer track using React/Vite, Node.js, Express, and MongoDB.

## 3. Database Architecture & Data Modelling

**Objective:** Plan the database structure and relationships.

**Technical Areas:**
- User role and authentication fields.
- Course ownership and instructor references.
- Course-to-lesson relationships.
- Student enrollment and learning progress.
- Course reviews and ratings.

**Key Outcome:** Designed a five-collection database structure consisting of Users, Courses, Lessons, Enrollments, and Reviews.

## 4. UI/UX Research

**Objective:** Establish the visual structure and navigation of EduCore.

**Design Areas:**
- Authentication interface.
- Instructor dashboard and course management.
- Course details and lesson viewing.
- Learning progress indicators.
- Consistent typography, spacing, and color palette.

**Key Outcome:** Prepared three core Figma viewports aligned with the planned application functionality.

## 5. Authentication & Security Research

**Objective:** Understand secure authentication implementation before development.

**Technical Areas:**
- Password hashing using bcryptjs.
- JWT generation and verification.
- Protected API routes.
- Role-based authorization.
- Secure user registration and login workflows.

**Key Outcome:** Established the planned authentication approach for the MVP.

## 6. Development Roadmap Research

**Objective:** Break down the capstone into manageable development phases.

**Planned Phases:**
- Sprint 13: Product planning and architecture.
- Sprint 14: Authentication and MVP foundation.
- Sprint 15: Core CRUD functionality.
- Sprint 16: Advanced features and UX improvements.
- Sprint 17: Testing, CI/CD, and deployment.

**Key Outcome:** Created a phased implementation roadmap based on the assigned capstone timeline.

## 7. AI-Assisted Technical Workflow

AI assistance was used for:
- Exploring alternative technical approaches.
- Understanding unfamiliar implementation concepts.
- Reviewing database design decisions.
- Troubleshooting development issues.
- Improving technical documentation.

All suggestions are subject to technical review and validation during implementation.

## Conclusion

AI served as a supporting research and development tool throughout the planning phase. The project scope, technology selection, architecture, and UI/UX direction were evaluated against the capstone requirements before being incorporated into the EduCore blueprint.
